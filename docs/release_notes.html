Release notes

Every version of lib-aeapps, newest first. Development versions are named after fruits.

Version 5.1 Mulberry

5.1.0Nov 2026
  • libremove module dependencies that the code does not use: contacts-api and multi-contact no longer depend on utilities, runtime-permissions no longer depends on core or utilities, and database-helpers no longer depends on core. Apps that used core or utilities classes only through these modules must now add them as dependencies

Version 5.0 Lingonberry

5.0.1Nov 2026
  • contacts-apifix IllegalStateException ("ContactsApiGateway not initialized") when initialize/initializeAsync is called again while contacts are still being read; later callers now wait for the read in progress and callbacks are only delivered once the gateway is ready
  • contacts-apia failed read no longer leaves the gateway stuck; it can be retried, and ContactsDataConsumer.onContactsReadFailed reports the error for initializeAsync
  • libpublished artifacts now expose AppCompat, RecyclerView, Fragment and Play Billing as compile dependencies where they are part of the public API
  • libpublish a sources jar for every module
  • libGitHub Actions CI (unit tests, lint, release build)
  • libcompileSdk 37
  • billing-clientPlay Billing Library 8; removed unused Guava dependency
  • contacts-apifix cursor and stream leaks, read only the columns needed, return null instead of crashing for an unknown contact id
  • contacts-apiinitializeAsync no longer crashes when called from a thread without a Looper
  • sms-apifix cursor leak on empty results; MessageInfo date, type and protocol are now populated
  • utilitiesCommonUtils.isPackageInstalled now checks the package passed in (it always returned true)
  • utilitiesIntentUtils.getUriIntent sets ACTION_VIEW
  • multi-contactfix search crash below Android 15 and a threading race while filtering
  • runtime-permissionsPermissionCheckingFragment requires every requested permission to be granted, not just the first
  • database-helpersCopiedDataBaseHelper keeps its path per instance, so two helpers no longer overwrite each other
  • coreSimpleGraphView no longer drifts on redraw or crashes when inflated from XML; RoundedImageView no longer crashes on non-bitmap drawables
  • billing-clientmigrate billing library #35
  • libmigrate to maven publish plugin #36
  • libmigrate android Gradle plugin version #37
  • libmigrate to kotlin dsl #38
  • libbuild structure changes
  • libuse JDK 17
  • agpupgrade to 9.4.1
