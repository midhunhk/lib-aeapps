Reusable building blocks for Android apps

lib-aeapps packages the boilerplate behind contacts, SMS, runtime permissions, Google Play Billing and in-app reviews into small modules. Use one, or use them all.

Get started

The library is published on JitPack. Add the repository once, then add the modules you need. Requires minSdk 26 (Android 8.0) and JDK 17.

settings.gradle.kts 
dependencyResolutionManagement {
    repositories {
        google()
        mavenCentral()
        maven { url = uri("https://jitpack.io") }
    }
}
app/build.gradle.kts 
val libAeAppsVersion = "v5.1.0"

// Pick individual modules…
implementation("com.github.midhunhk.lib-aeapps:core:$libAeAppsVersion")
implementation("com.github.midhunhk.lib-aeapps:contacts-api:$libAeAppsVersion")

// …or everything at once
implementation("com.github.midhunhk.lib-aeapps:aeapps:$libAeAppsVersion")

Use the release tag, including the leading v, as the version. Library modules do not declare permissions; add the ones you use (for example READ_CONTACTS) to your app's manifest.

Modules

Each module is a separate artifact. Modules bring in the ones they depend on, so adding contacts-api also adds core.

core

Core

Shared models, custom views, a toolbar base activity, in-app reviews and common resources.

utilities

Utilities

Helpers for intents, dialogs, phone calls, texts, package checks and formatting.

contacts-api

Contacts API

Read and cache device contacts, look up phone numbers and pictures, pick a random contact.

Uses core

sms-api

SMS API

Count and read messages by folder or by contact through a simple gateway.

Uses core

runtime-permissions

Runtime permissions

Base activities, a fragment and a checker that handle requesting and reacting to permissions.

multi-contact

Multi-contact picker

A searchable screen for selecting several contacts, plus a single-contact picker fragment.

Uses core

billing-client

Billing client

A lifecycle-aware wrapper around Google Play Billing Library 8 for one-time products.

mocks

Mocks

Fake contacts and messages for demos and unit tests. Best added as a test or debug dependency.

Uses core

Sample app

A sample app on Google Play shows the contacts API, the multi-contact picker and more, built on the library. Its source lives in the sample folder.

The Play Store build leaves out the SMS feature, because Google Play restricts the READ_SMS permission. Build the sample from source to try it.
