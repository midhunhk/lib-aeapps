PermissionCheckingFragment

abstract class PermissionCheckingFragment : Fragment

An abstract Fragment that can check for Runtime Permissions if your app target is above Lollipop Use RuntimePermissionChecker if you need to extend any other component The onCreateView method is used to check for the permission and returns an empty FrameLayout to the Activity that hosts this fragment. Based on the permission check result, the below methods would be invoked and can return the appropriate View for that scenario setupViewWithPermission If permission is granted setupViewWithoutPermission If permission is not granted
