fun acknowledgePurchase(purchase: Purchase)

Acknowledge a purchase. Required for all non-consumable one-time products and all subscriptions. Purchases that are not acknowledged within 3 days will be automatically refunded. This client currently focuses on INAPP (consumable by default), so this is an example.
